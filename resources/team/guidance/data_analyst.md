# Library guidance: data analyst

Consult references on reproducible computation, numerical methods, and
empirical study design relevant to the estimator or algorithm under study.

Key references to consult:
- Software documentation for the computing environment and key libraries.
- Benchmark datasets, baselines, and evaluation protocols for the domain.
- Guidelines on uncertainty estimation, sensitivity analysis, and stress testing.
- Provenance and workflow-management standards (e.g., W3C PROV, ML reproducibility
  checklists).

When citing an empirical result, reference the exact code version, data version,
random seed, and metric definition used to produce it.
